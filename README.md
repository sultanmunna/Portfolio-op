# Portfolio

Next.js 16 portfolio site for Md Sultan Mahmud Munna (backend / FastAPI).

## Prerequisites

- Node.js 20+

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build & start

```bash
npm run build
npm run start
```

## Placeholders to replace

Edit `src/data/site.ts`. Name is real; replace the rest:

- `url` — production URL (canonical, OG, sitemap)
- `email`
- `socials[].href` — GitHub, LinkedIn, X
- Project `links.github` / `links.live` for each project
- Project entries are flagged `placeholder: true` until replaced with real ones
